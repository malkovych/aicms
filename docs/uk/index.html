AICMS

CMS, у якій AI-агенти працюють з контентом так само природно, як люди.

Опиши модель один раз. AICMS сам згенерує API, MCP-інструменти для агентів, адмінку для людей і типи для фронтенду. Модулі додаються як цеглинки, а кожна зміна агента проходить перевірку і відкочується одним кліком.

Принципи

Шість правил, які тримають систему простою

Кожне рішення в архітектурі перевіряється цими правилами. Якщо фіча їх ламає, вона йде в модуль або не робиться зовсім.

Одна схема, усе інше генерується

Модель описується в TypeScript один раз. З неї виходять таблиці, валідація, REST, MCP, форми Studio, типи й документація для агентів.

Кожна дія — це Action

Створити запис, згенерувати alt-текст, провести SEO-аудит: одна сутність з input/output-схемою, правами й хуками. Людина й агент проходять той самий шлях.

Агент не пише в прод напряму

Зміни агента лягають у changeset, проходять перевірки й рев'ю. Журнал подій дозволяє відкотити що завгодно.

Модуль — одна папка

Один файл-маніфест оголошує, що модуль дає і що йому потрібно. Ніякої глобальної каші з хуків і пріоритетів.

Мінімум файлів

Проєкт — це конфіг, папка моделей і, за потреби, власні модулі. Усе згенероване лежить у .aicms/ і не комітиться.

Будь-який фреймворк і рантайм

Ядро на веб-стандартах Request/Response: Node, Bun, Deno, Cloudflare Workers. Адаптери для всіх популярних фронтендів.

Архітектура

Чотири шари і один конвеєр посередині

Агенти, люди й фронтенди заходять через різні входи, але кожен виклик перетворюється на Action і проходить один і той самий конвеєр ядра. Саме ядро генерує всі входи зі схем.

Конвеєр Action: однаковий для всіх

Будь-який вхід лише викликає Action. Валідація, перевірка прав, хуки модулів, запис у журнал і подія для вебхуків відбуваються в одному місці, тому агент не може обійти правила, які діють для людини.

  • валідаціяStandard Schema, помилка з назвою поля
  • політикаscopes до рівня поля, бюджет, режим рев'ю
  • журналхто, що, коли, через який вхід
  • подіявебхук фронтенду, SSE для агентів

Шість таблиць ядра на будь-який сайт

Кількість моделей не змінює схему бази. Записи зберігаються як JSON-документи, а поля з indexed: true отримують індекси на виразах у SQLite і Postgres.

  • entriesпоточний стан кожного запису
  • versionsнезмінна історія
  • changesetsгілки змін від агентів і людей
  • eventsжурнал усіх Actions
  • mediaфайли, метадані, alt-тексти
  • tokensтокени агентів, лише у вигляді хешів
Словник

Сім понять, і більше вчити нічого

Людина орієнтується в системі за п'ять хвилин. Агент отримує ці ж поняття через cms_describe.

Model
Схема типу контенту разом з інструкціями для агента
post, product, review
Entry
Один запис моделі з історією версій
«Як обрати SPF на зиму»
Block
Цеглинка всередині rich-контенту
paragraph, image, cta
Action
Будь-яка операція з типізованим входом, виходом і правами
post.draft, seo.audit
Module
Пакет із моделями, блоками, Actions, хуками й панелями Studio
seo, commerce, reviews
Agent
Ідентичність агента: права, бюджет, режим рев'ю
writer, seo, moderator
Changeset
Набір запропонованих змін, що чекає перевірки
«writer: 3 нові статті»
Структура проєкту

Сайт описують два види файлів

У WordPress логіка сайту розкидана між темою, плагінами й functions.php. В AICMS вона живе в моделях і модулях, а все інше генерується.

Модулі

Модулі складаються як Lego

Модуль просить можливість, а не конкретний пакет. Натисни на цеглинки: залежності підтягнуться самі, а інструменти агента й меню Studio перебудуються.

    Агенти

    Будь-який агент підключається за хвилину

    Вісім входів покривають усі популярні способи, якими агенти працюють сьогодні. Агент бачить тільки ті інструменти, на які має права.

    MCP

    /mcp · npx aicms mcp

    Claude, Cursor, ChatGPT і будь-який MCP-клієнт. Streamable HTTP або stdio.

    REST

    /api/v1/*

    Звичайні HTTP-запити з токеном агента. n8n, Make, скрипти.

    OpenAPI

    /openapi.json

    Function calling у будь-якій LLM, LangChain, LlamaIndex.

    GraphQL

    /graphql

    Складні вибірки для фронтендів і аналітичних агентів.

    SDK

    @aicms/client · pip install aicms

    Власні агенти на TypeScript і Python з типами зі схем.

    Events

    webhooks · /events (SSE)

    Агент реагує на зміни: новий відгук, нове замовлення, публікація.

    A2A

    /.well-known/agent.json

    Картка агента для протоколу агент-до-агента.

    Discovery

    /llms.txt · /.well-known/aicms.json

    Агент сам дізнається, які моделі й дії тут є.

    Інструменти агента

    Чотири інструменти ядра, чотири згенеровані на кожну модель, плюс Actions встановлених модулів. Інструмент чернетки показує лише ті поля, які агенту дозволено змінювати.
