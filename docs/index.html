Principles

Six rules that keep the system simple

Every architecture decision is checked against these rules. If a feature breaks them, it becomes a module or it doesn't get built.

One schema, everything else generated

A model is described once in TypeScript. Tables, validation, REST, MCP, Studio forms, types and agent docs all come from it.

Every operation is an Action

Creating an entry, generating alt text, running an SEO audit: one shape with an input/output schema, scopes and hooks. People and agents take the same path.

Agents never write to production directly

An agent's changes land in a changeset and go through checks and review. The event log can roll back anything.

A module is one folder

One manifest file declares what the module provides and what it needs. No global soup of hooks and priorities.

As few files as possible

A project is a config, a models folder and, if needed, your own modules. Everything generated lives in .aicms/ and is never committed.

Any framework, any runtime

The kernel is built on web-standard Request/Response: Node, Bun, Deno, Cloudflare Workers. Adapters for every popular frontend.

Architecture

Four layers and one pipeline in the middle

Agents, people and frontends come in through different gates, but every call becomes an Action and runs through the same kernel pipeline. The kernel itself generates every gate from the schemas.

One Action pipeline for everyone

Every gate just calls an Action. Validation, permission checks, module hooks, the log entry and the webhook event all happen in one place, so an agent can't sidestep the rules that apply to a person.

  • validateStandard Schema, errors name the field
  • policyfield-level scopes, budget, review mode
  • logwho, what, when, through which gate
  • emitfrontend webhook, SSE for agents

Six core tables for any site

The number of models never changes the database schema. Entries are stored as JSON documents, and fields marked indexed: true get expression indexes in SQLite and Postgres.

  • entriescurrent state of every entry
  • versionsimmutable history
  • changesetsbranches of changes from agents and people
  • eventslog of every Action
  • mediafiles, metadata, alt text
  • tokensagent tokens, stored only as hashes
Vocabulary

Seven concepts, and nothing else to learn

A person finds their way around in five minutes. An agent gets the same concepts through cms_describe.

Model
A content type's schema, together with instructions for agents
post, product, review
Entry
One record of a model, with its version history
“How to choose SPF for winter”
Block
A brick inside rich content
paragraph, image, cta
Action
Any operation with a typed input, output and scopes
post.draft, seo.audit
Module
A package of models, blocks, Actions, hooks and Studio panels
seo, commerce, reviews
Agent
An agent identity: scopes, budget, review mode
writer, seo, moderator
Changeset
A set of proposed changes waiting for checks and review
“writer: 3 new posts”

Modules

Modules snap together like Lego

A module asks for a capability, not a specific package. Tap the bricks: dependencies come along on their own, and the agent's tools and the Studio menu rebuild themselves.

    modules/reviews/module.tsthe whole module
    export default defineModule({
  name: "reviews",
  requires: ["commerce"],
  uses: ["product"], // access to other models is explicit
  models: {
    review: { fields: {
      product: field.ref("product"),
      rating:  field.number({ min: 1, max: 5 }),
      status:  field.enum(["pending", "published"]),
    }},
  },
  actions: {
    moderate: action({
      description: "Approve or reject a review",
      scope: "reviews:write",
      input: { id: field.id(), ok: field.boolean() },
      run: ({ input, ctx }) => ctx.draft("review", …),
    }),
  },
  on: { "changeset.merged": notifyModerator },
  studio: { nav: { label: "Reviews" } },
})
    Agents

    Any agent connects in a minute

    Eight gates cover every popular way agents work today. An agent only sees the tools its scopes allow.

    MCP

    /mcp · npx aicms mcp

    Claude, Cursor, ChatGPT and any MCP client. Streamable HTTP or stdio.

    REST

    /api/v1/*

    Plain HTTP with an agent token. n8n, Make, scripts.

    OpenAPI

    /openapi.json

    Function calling in any LLM, LangChain, LlamaIndex.

    GraphQL

    /graphql

    Generated from your models; references resolve to entries, same permissions.

    SDK

    @aicms/client · pip install aicms

    Your own agents in TypeScript and Python, typed from the schemas.

    Events

    webhooks · /events (SSE)

    Agents react to changes: a new review, a new order, a publish.

    A2A

    /.well-known/agent-card.json · /a2a

    Other agents discover the site and call its Actions as skills.

    Discovery

    /llms.txt · /.well-known/aicms.json

    An agent finds out on its own which models and actions exist.

    The agent's tools

    Four kernel tools, four generated per model, plus the Actions of installed modules. A draft tool only lists the fields the agent is allowed to write.

    cms_describemodels, fields, guides, examples, available actions
    cms_searchfull-text search across models
    post_list / post_getreads with field selection and pagination
    post_draftcreate or change an entry inside a changeset
    post_deletepropose deleting an entry
    cms_submitsend the changeset for review
    cms_changesmy changesets and reviewer comments
    seo_audit …module Actions, if scopes allow

    Field-level scopes

    post:update.seo lets an agent change SEO fields only. The rest of the model isn't even in its tool schema.

    Review mode

    human or auto, per agent. New agents default to human.

    Budgets

    Limits on actions per hour and on changeset size. Going over pauses the agent until the window resets.

    Kill switch

    One command revokes the agent's tokens and rejects every change it hasn't had merged.

    • storageThe database is the source of truth. A git-sync module mirrors published content to Markdown files and turns pull requests into changesets.

    • pythonThe Python SDK shipped in phase 1, together with the TypeScript one.
